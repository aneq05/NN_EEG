# Notebooks

Projekt jest odtwarzalny przez skrypty w `src/`. Folder `notebooks/` zostal
zostawiony jako miejsce na reczne eksperymenty lub prezentacje wynikow.

Sugerowany podzial, jesli potrzebne beda notebooki do oddania:

- `01_eda.ipynb` - wykresy i komentarze EDA,
- `02_model_training.ipynb` - przeglad treningu i Optuny,
- `03_xai_uncertainty.ipynb` - kalibracja, niepewnosc, PFI i LIME.

Wszystkie artefakty potrzebne do takich notebookow sa juz zapisane w `outputs/`.
